# 股票精灵（Stock Wizard）产品需求文档

> 版本：v1.0  
> 日期：2026-09-15  
> 产品负责人：鲁力铭  
> 状态：已确认，进入实现

---

## 1. 产品愿景

把股票市场做成一部可玩的《神奇宝贝》图鉴。

用户不再面对冷冰冰的行情表，而是像训练家一样：在野外偶遇一只「股票精灵」，观察它的属性与招式，判断能否捕捉（加入自选），再持续养成、分析、组队。核心体验是 **图鉴收集 + 捕捉养成 + 观察分析**，视觉沿用宝可梦红白机时代的像素红白风。

一句话定位：**一部能捉、能看、能研究的股票宝可梦图鉴。**

---

## 2. 问题与机会

| 现状 | 机会 |
| --- | --- |
| 传统行情 App 信息密度高、情绪冷、留存靠刚需 | 用图鉴收集欲降低「看盘门槛」 |
| 自选股像购物车，缺少仪式感 | 「捕捉」把加自选变成一次可玩事件 |
| 技术分析对新手不友好 | 用 HP / 攻击 / 防御等宝可梦属性翻译财务与行情 |
| 同类产品同质化 | 红白机像素风 + 训练家叙事形成差异 |

---

## 3. 目标用户

- **主用户**：对股市好奇、但被专业软件劝退的年轻人；喜欢二次元 / 复古游戏。
- **次用户**：已有自选习惯、想用更有趣方式复盘的轻度投资者。
- **非目标**：专业交易员、需要 Level-2 盘口 / 下单的用户。本产品不做交易。

---

## 4. 产品原则

1. **先好玩，再专业**：每个金融概念都必须有游戏翻译，不允许裸奔指标。
2. **红白机克制**：红、白、黑、少量黄蓝；粗像素边框；菜单式导航；不堆现代卡片阴影。
3. **捕捉有仪式**：加自选必须经过遭遇 → 投球 → 摇晃判定，而不是一个「+」按钮。
4. **图鉴有完成欲**：编号、遇见/捕捉状态、类型、描述文案完整。
5. **分析要可读**：六维属性 + 招式（行情事件）+ 适性（行业），而不是 K 线指标墙。
6. **本地即玩**：首版用内置精灵图鉴与模拟行情，不依赖登录与券商接口。

---

## 5. 核心玩法循环

```
开机标题 → 主菜单
   ├─ 野外遭遇：随机遇一只未捕捉/野生精灵
   ├─ 投球捕捉：摇晃 1~3 次，成功率受「野生度」影响
   ├─ 收入图鉴：状态从「未遇见」→「已遇见」→「已捕捉」
   ├─ 编入队伍：最多 6 只出战（重点观察）
   └─ 观察分析：看走势、六维、招式日志，再决定放生或继续养成
```

成功体验：用户会主动去「再遇一只」，而不是打开软件只看一眼涨跌。

---

## 6. 信息架构

```
启动画面（PRESS START）
 └─ 主菜单
     ├─ 精灵图鉴 …… 编号列表 + 详情
     ├─ 野外草地 …… 遭遇 / 捕捉
     ├─ 我的队伍 …… 最多 6 只自选
     ├─ 训练家证 …… 收集进度、称号
     └─ 设置说明 …… 玩法与免责声明
```

详情页内可进入「观察」与「分析」两个子页签。

## 7. 功能需求

### 7.1 启动与主菜单

- 全屏红白机标题：「股票精灵」「STOCK WIZARD」。
- 像素精灵剪影左右走动，底部 `PRESS START` 闪烁。
- 主菜单四项（图鉴 / 草地 / 队伍 / 训练家），方向键或点击选择，有选中框动画。
- 首次进入自动创建训练家档案（本地）。

### 7.2 精灵图鉴（Pokedex）

对标宝可梦图鉴列表。

| 字段 | 游戏翻译 | 数据来源 |
| --- | --- | --- |
| No. | 全国图鉴编号 | 内置图鉴 |
| 名称 | 精灵名 | 股票简称 |
| 代号 | 内部编号 | 股票代码 |
| 类型 1/2 | 属性 | 行业 / 风格（成长、价值、高波等） |
| 遇见状态 | 剪影 / 彩色 | 是否遭遇过 |
| 捕捉状态 | Poké Ball 标记 | 是否自选 |
| 简述 | 图鉴说明 | 撰写的精灵设定 |

交互：

- 列表显示编号、名称、球标；未遇见显示 `?????` 与剪影。
- 点击进入详情：像素立绘、类型徽章、身高体重（映射市值/估值）、图鉴文案。
- 已捕捉可从详情「编入队伍」或「放生」。
- 支持按名称/代码搜索、按类型筛选。

### 7.3 野外草地（遭遇 + 捕捉）

对标草丛遇敌。

- 进入草地后，训练家在像素草地上移动（点击「走一步」或自动巡航）。
- 随机遭遇一只精灵：弹出战斗框「野生的 XXX 跳了出来！」。
- 可选行动：
  - **观察**：先看今日涨跌与一句习性，不捕捉也可标记「已遇见」。
  - **投球**：播放投球 → 球晃 1~3 下 → 成功/挣脱。
  - **逃跑**：结束遭遇。
- 捕捉成功率：

```
基础率 = 45%
+ 已遇见奖励 10%
- 野生度（波动）惩罚 0~25%
+ 连续投球衰减（同一只连投第二次 -8%）
保底：最低 18%，最高 88%
```

- 已捕捉的精灵再遭遇时文案变为「XXX 的伙伴出现了」，可「观察」不可重复捕捉。
- 队伍已满 6 只时仍可捕捉进图鉴，但提示「放进电脑（图鉴仓库），未编入出战」。

### 7.4 我的队伍（自选）

- 最多展示 6 个槽位，空槽显示 `————`。
- 每只显示：立绘、等级（由近况映射）、HP 条（用日内涨跌映射气血观感）、类型。
- 可换位（上移/下移）、放生（移出自选，图鉴仍保留「已捕捉」或降为「已遇见」，见 8.3）。
- 点击进入该精灵的观察/分析。

### 7.5 观察

把「看盘」做成野外观察记录。

- 像素折线：近 20 个交易时点的模拟/内置走势。
- 今日行情条：现价、涨跌、高低、成交热度。
- 习性文本：根据涨跌与类型生成 1~2 句图鉴口吻描述。
- 招式日志：把近期波动翻译成招式名（如「突击 +3.2%」「铁壁回撤」）。

### 7.6 分析

把基本面/交易特征翻译成宝可梦能力。

六维（0~100 展示，对内有计算规则）：

| 能力 | 含义 |
| --- | --- |
| HP 体力 | 价格稳定性（波动越低越高） |
| 攻击 | 上行爆发 / 近段涨幅 |
| 防御 | 估值安全垫 / 回撤抗性 |
| 特攻 | 成长性（行业成长属性加权） |
| 特防 | 分红与现金流防御 |
| 速度 | 成交活跃、换手 |

- 像素雷达或六条能力槽。
- 显示特性（如「盛宴」「畏光」）、弱点与抗性（相对其他类型的通俗解释）。
- 给出一句训练家建议：适合观察 / 适合组队 / 波动过大慎捉。

### 7.7 训练家证

- 训练家名（可改）、编号、称号。
- 图鉴完成度：遇见数 / 捕捉数 / 总数。
- 称号规则：
  - 捕捉 1：新人训练家
  - 捕捉 6：正式训练家
  - 捕捉 12：图鉴研究员
  - 捕捉 20：冠军挑战者
  - 集齐：图鉴完成者
- 出战队伍缩略图。

### 7.8 设置与声明

- 音效开关（若实现短音效）。
- 重置图鉴（需二次确认）。
- 免责声明：本产品为娱乐向图鉴，不构成投资建议，数据为演示/模拟。

## 8. 游戏世界观与映射规则

### 8.1 类型（属性）

| 类型 | 代表行业/风格 | 克制关系（玩法文案，非真实金融） |
| --- | --- | --- |
| 电 | 科技、半导体 | 克水，怕地 |
| 火 | 能源、周期上行 | 克草，怕水 |
| 水 | 消费、必选 | 克火，怕电 |
| 草 | 医药、农业 | 克水地，怕火 |
| 钢 | 制造、工业 | 抗许多，怕火 |
| 超能 | 金融、平台 | 克格斗，怕恶 |
| 飞行 | 互联网、传媒 | 克草格斗，怕电 |
| 岩石 | 地产、基建 | 克火飞，怕水草 |
| 恶 | 高波动题材 | 克超能，怕格斗 |
| 一般 | 综合、指数成分 | 无克，怕格斗 |

一只精灵可有 1~2 个类型。

### 8.2 外形与「身高体重」

- 每只精灵有一张像素立绘（按类型色板生成/绘制，避免使用官方宝可梦形象）。
- 身高 ← 市值体量档（小型 / 中型 / 传说级）。
- 体重 ← 估值重量（PE/风格：轻盈成长 vs 沉重价值）。

### 8.3 捕捉与放生状态机

```
未遇见  --遭遇--> 已遇见  --捕捉成功--> 已捕捉
已捕捉  --放生--> 已遇见（图鉴记录保留，队伍移除）
已捕捉  --再遭遇--> 仅观察，不可再捉
```

### 8.4 等级

- Lv = 10 + 近 20 日累计表现映射，范围 Lv.5 ~ Lv.50。
- 仅用于展示与队伍排序，不升级技能树（首版不做进化）。

### 8.5 文案语气

图鉴说明使用第一代图鉴口吻：短句、略古怪、把公司特征写成生物习性。例如：

> 栖息在科技高地。晴天时电流旺盛，阴天则潜伏充电。据说看见它的训练家会整夜研究财报。

禁止承诺收益，禁止「稳赚」「必涨」。

## 9. 视觉与交互规范

### 9.1 风格关键词

宝可梦红 / 初代图鉴 / Game Boy 菜单 / 粗像素 / 红白机。

### 9.2 色彩

| 角色 | 色值 |
| --- | --- |
| 图鉴红 | `#DC0A2D` |
| 深红 | `#8B0E22` |
| 屏幕白 | `#F4F0E6` |
| 墨黑 | `#1A1A1A` |
| 选中黄 | `#F7D51D` |
| GB 绿（战斗框） | `#9BBC0F` / `#0F380F` |
| 涨 | `#C41E3A`（中国习惯红涨，与机身红区分用更深的「战斗红」） |
| 跌 | `#2D5A27` |

涨跌在像素风下用 ▲ ▼ 与深色块，避免扁平渐变。

### 9.3 字体与控件

- 英文/数字：像素等宽（Press Start 2P 或等效）。
- 中文：像素中文或清晰点阵感黑体，字号偏大，少用细字。
- 按钮：厚边框、按下去有 2px 位移。
- 对话框：左上姓名框 + 下方文本框，逐字出现（可跳过）。

### 9.4 动效（克制）

- 标题闪烁、菜单光标跳动、投球摇晃、HP 条递减、遇敌闪白。
- 不做视差滚动、不做毛玻璃。

### 9.5 适配

- 桌面优先，居中一台「图鉴机」最大宽约 960px。
- 窄屏改为单列，底部保留四键导航（图鉴 / 草地 / 队伍 / 训练家）。

## 10. 数据需求

### 10.1 首版图鉴规模

内置 **24 只** 股票精灵，覆盖科技、消费、能源、金融、医药、制造、互联网、地产等类型，中美市场各一部分，保证类型与稀有度分布好玩。

每只至少包含：编号、代码、名称、市场、类型、稀有度、图鉴文案、基础六维、初始行情序列。

### 10.2 行情

- 首版：**内置历史片段 + 前端定时微扰**，模拟「还在动」的观察感。
- 不接券商、不登录。界面标注「演示行情」。
- 后续迭代可替换为真实行情源，映射规则不变。

### 10.3 存档

`localStorage` 保存：训练家名、遇见/捕捉集合、队伍顺序、捕捉次数、设置。  
刷新不丢档。提供重置。

## 11. 非功能需求

- 现代浏览器可运行，无需后端。
- 首屏可交互 < 2s（本地资源）。
- 可玩路径不断网可用。
- 无障碍：键盘可操作主菜单与捕捉选项。
- 法律：显著免责声明；不提供下单。

## 12. 首版范围（MVP）

**做：**

- 启动画面、主菜单
- 24 只图鉴列表 / 搜索筛选 / 详情
- 草地遭遇与投球捕捉
- 6 人队伍、放生、换位
- 观察（折线 + 招式日志）
- 分析（六维 + 建议）
- 训练家证与本地存档

**不做（后续）：**

- 真实交易与真实 Level-2
- 精灵进化 / 繁殖 / 对战数值结算
- 账号体系、社区、排行榜
- 官方宝可梦 IP 形象与音效翻录

---

## 13. 成功标准

1. 新用户 1 分钟内完成：开机 → 遇敌 → 捕捉 → 在队伍中看到它。
2. 图鉴页一眼能分清未遇见 / 已遇见 / 已捕捉。
3. 任意精灵的分析页能用游戏语言讲清「它是什么样的股票」。
4. 视觉稳定在红白像素风，不混入现代看板风格。
5. 重置存档后游戏回到初始状态。

---

## 14. 风险与约束

- **IP**：只借鉴「图鉴 / 捕捉 / 红白机菜单」的交互原型，不使用皮卡丘等官方角色、不使用官方精灵图。
- **合规**：娱乐产品，避免荐股话术。
- **数据**：演示行情可能与真实市场不符，必须标注。
